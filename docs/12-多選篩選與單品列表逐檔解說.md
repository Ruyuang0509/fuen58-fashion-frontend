# 12　第十五輪・子輪 3：多選篩選、單品列表

2026-10-06。規格在 [09](09-內容與功能拓展-規格.md) §4；使用者「開工」。中途兩句回饋也在這一子輪處理：「沒人會在 footer 放這個」（頁尾的會員欄拿掉）；頂欄圖示要有連結以外的作用（下一份文件）。

## 做了什麼（一句話）

一句話列的場合、類別、尺寸可以多選，句子讀成「上班或約會」「S 或 M」；單品有了自己的列表頁 `/products`，用同一套句法篩品牌（多選）、色系（多選）、價格三檔、尺寸（多選）、有貨、排序，搜尋併進來；下拉格子不再是原生 `<select>`，是自己做的、鍵盤與讀屏都能用的清單。

## 逐檔

### 格子

- `src/components/ClausePicker.vue`（新）：句子裡的一格。外觀是粗體加強調色底線的幾個字加一個小箭頭；點開是 `role="listbox"` 的清單（多選時 `aria-multiselectable`），每項 `role="option" aria-selected`。鍵盤：按鈕上按方向鍵開；清單裡方向鍵移、Home／End、空白鍵或 Enter 勾、Esc 關並把焦點還給按鈕、Tab 離開也關；點外面關（capture 階段聽 `pointerdown`，點到別格時這格先關）。多選不自動關，有「好了」；單選選完就關。片語：沒選 → 那格的「不限」說法；一個 → label；兩個以上 → short 連成「A、B 或 C」，英數字之間加空白（「S 或 M」）。手機（≤ 36rem）變成底部面板加一層暗底。選項可帶 `swatch`（顏色那格的色點）。
- `src/components/SentenceBar.vue`：五個原生 `<select>` 換成 `ClausePicker`；場合、類別、尺寸 `multi`。Flip 的位置改在送出新值之前記（`change()`），多選時每勾一個都記一次、動一次。收合成一行的摘要，多選用「／」連。
- `src/components/OutfitCard.vue`：`preferredSize` 可以是陣列，挑這件有的第一個。
- `src/components/Icon.vue`：加 `check`。

### 條件與資料

- `src/composables/useFilters.js`：`splitList`（逗號拆、去空去重）與 `listFrom`（只留選項裡有的值）。場合、類別、尺寸是陣列；網址 `?occasion=work,date`；不認得的值（`?occasion=foo`）直接丟掉、重複的去掉。
- `src/filters/options.js`：尺寸加 F（單一尺寸）與童裝 110／120／130；新增 `PRODUCT_CATEGORIES`（第一項「全部單品」）、`PRICES`（兩千以下／兩千到四千／四千以上，各自對應 `priceMin`／`priceMax`）、`STOCKS`、`SORTS`。
- `src/products/colourFamily.js`（新）：商品各自的色名太細不能當條件，用 hex 算 HSL 分成十一個色系：黑、白、灰、米駝、棕、黃、綠、藍、紫、粉、紅。門檻是對著目前 48 個商品顏色調的——明度 < 0.18 黑；明度 ≥ 0.87 且彩度 < 0.6 白（米白、象牙白、骨白、奶油都算白）；彩度 < 0.06 灰（炭灰、鼠灰、岩灰）；色相 15–60° 裡彩度 ≥ 0.6 是黃（芥黃），其餘亮的米駝（燕麥、沙、麥、駝）、暗的棕（菸草、茶、鐵鏽、卡其）；60–75° 低彩度的橄欖算綠；到 170° 綠、255° 藍、300° 紫；其餘紅系裡亮的粉（櫻粉、淺粉）、暗的紅（暗紅、酒紅）。契約建議正式版在顏色表加一欄 `family` 由後台填。
- `src/api/index.js`：`getOutfits` 的場合、類別、尺寸收陣列或逗號字串，任一符合；尺寸只看選到類別的單品。`getProducts` 擴成 `q`、`category`、`brands`、`colours`（色系）、`sizes`、`priceMin`／`priceMax`，加原本的 `ids`、`theme`、`brand`、`exclude`、`sort`、`inStock`；關鍵字比對抽成 `matchesWords`；`searchProducts` 變成薄包裝。

### 單品列表

- `src/views/ProductsView.vue`（新）`/products`，取代 `SearchView.vue`（刪）。句子：「『關鍵字』，找〔外套〕，〔霧岸或半日〕的，〔米駝〕色，〔兩千以下〕，尺寸〔S 或 M〕，〔只看有貨〕，照〔新上架〕排，共 N 件。」沒選品牌時不說「的」、沒選顏色時不說「色」。條件全在網址；排序是預設值就不寫。零件結果：一句話、「清除條件」、「看全部穿搭」，加同路線的單品（和以前的搜尋無結果同一套）。
- `src/router/index.js`：`/products`；`/search` 轉址到 `/products` 並保留查詢字串（舊連結還在別人手上）。
- `src/components/SiteHeader.vue`：搜尋送到 `/products?q=`；帶關鍵字的單品頁搜尋框常開。
- `src/components/HomeShelves.vue`、`src/components/SiteFooter.vue`：「看全部」「找單品」連到 `/products`。頁尾**拿掉「會員」欄**（登入／註冊在頂欄；使用者：「沒人會在 footer 放這個」），找單品欄加「全部單品」。

### 驗收與文件

- `scripts/expand-check.mjs` 第三段 26 項（共 99）：`?occasion=work,date` 12 套、片語「上班或約會」；`?size=S,M&category=outer` 15 套、「S 或 M」；`?occasion=foo,work&size=M,M` 不認得與重複的丟掉 → 2 套；鍵盤整圈（方向鍵開、清單拿到焦點、空白鍵勾第一個 → 網址 `?occasion=work` 且清單不關、再勾一個 → `work,date`、`aria-selected` 兩項、Esc 關且焦點回按鈕）；`/products?brand=wuan,banri` 13、`?colour=pink` 2、`?colour=black,grey` 對資料算、`?price=lt2000` 26 且每件 < 2,000、`?size=110` 3、關鍵字＋排序＋有貨、舊 `/search` 轉址、零件結果的「清除條件」、顏色清單十一個色點、桌機浮在格子下／手機底部面板、開著清單時沒有東西溢出。第一段的頁尾檢查改成「沒有會員欄、沒有登入／註冊」。
- `scripts/shop-check.mjs`：排序那格不是 `<select>` 了，改讀 `.pick` 的字。
- `docs/api-契約草案.md` 4.2：多值逗號分隔、`colour` 是色系代碼、價格三檔對應 `priceMin`／`priceMax`、不認得的值請忽略。

- `npm run build` 成功；`expand-check` 99／99、`shop-check` 60／60、`member-check` 39／39，三支都在 1252×699 與 390×844 跑；無頭 Chrome 沒有主控台錯誤。
