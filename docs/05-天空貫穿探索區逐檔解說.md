# 05　第十一輪：天空貫穿探索區、穿搭頁、新頂欄

2026-10-06。基底補完後使用者說 GO，並加三句：「Navbar 當前設計我不喜歡」「善用 icon」「畫面要留有呼吸空間」「善用 hover」。
這一輪的題目是**把「今天」這條線拉過整個探索區**——第九、十輪之後的站，特別的東西只活在首頁第一屏，捲過地平線後每一頁都是通用的電商版型。

## 一眼看完

- **同一片天空貫穿探索區**：首頁、路線頁、穿搭頁、全部穿搭都在天空下（`SkyPage` 骨架）；路線頁用那條路線自己的時刻（龐克＝晚上九點的雨、蘿莉塔＝下午三點的茶會…），穿搭頁用今天的天氣染上路線的顏色。
- **穿搭自己的一頁** `/outfits/:id`：「今天為什麼是這套」由天氣對每件的厚薄、布料算出幾句話；三件掛在天空下；可以換一件（同路線同類別）、選尺寸、整套加入；滑過單品清單，人形裡那一件會提出來。
- **衣服會動**：掛著的衣服慢慢晃、被天空的風推歪、滑過去盪一下。
- **新頂欄**：站名（襯線）加「現在的天氣」一個小圖示；右邊四件事各一個細線圖示配小字；搜尋點了才滑出；滑過畫一條線；件數是整條頂欄唯一的強調色。
- **呼吸空間**：頂欄 4.4rem、段落間距 4.8rem、卡片間距加大、卡片內距加大。
- **一句話列會回話（一半）**：改條件時卡片重新排列有位移過程；標題說「N 套」。

## `src/components/SkyPage.vue`：探索區的骨架

把第八輪首頁裡「天空＋浮動頂欄＋地平線＋捲出即停」那一整套抽出來，首頁、路線頁、穿搭頁、全部穿搭共用。

- 屬性：`weather`（雲雨霧）、`hour`（固定時刻；null＝現在）、`tint`（染色）、`height`／`minHeight`（第一屏高度）、`skipTarget`。
- 兩個插槽：`hero`（天空裡的內容）與預設（底下的內容，拿得到 `heroHeight`，一句話列的收合門檻用它）。
- **風**：滑鼠在天空上移動，除了推雲（`sky.stir`），也算出一個 −1～1 的 `--wind` 寫在 `.hero` 上，沒人推就每 80ms 衰減；`OutfitLook` 讀它。
- `defineExpose` 給首頁的量測用（`webgl()`、`running()`、`dark()`、`pastHero()`）。
- **手機版的一個 bug**（這輪抓到並修掉）：窄螢幕時 `.hero-body` 原本改成 `position: static` 好讓高度跟著內容，結果文字被絕對定位的天空畫布蓋住——static 的元素畫在所有定位元素後面。改成 `position: relative; inset: auto; z-index: 2` 就好。截圖裡只看得到破折號、看不到字，就是這個。

## `src/components/SiteHeader.vue`、`src/components/Icon.vue`：頂欄

- `Icon.vue`：十二個 24×24、1.6 粗的描邊圖示（搜尋、衣架、提袋、人、晴、雲、雨、月、相機、往下、換、關），自己畫的——只要十來個，而且要和天空、款式圖同一種「細線」的語彙。顏色跟文字、大小跟字級。
- 站名用 Noto Serif TC 600，和第一屏的大字同一個字。旁邊一個小天氣圖示（夜裡是月亮），**滑到站名**才展開「臺北 18°，有雨」。
- 右邊：搜尋、全部穿搭、購物車、會員，每一項是圖示在上、小字（0.68rem、字距 0.14em）在下，平常 78% 不透明；**滑過**變實、圖示往上 1px、底下一條 1px 的線從中間畫出來（目前所在的頁面也畫著）。
- 搜尋：平常只是圖示，點了輸入框從右邊滑出 13rem 並取得焦點，Esc 收回；沒打字就離開也收回；在搜尋結果頁常開並顯示關鍵字。
- 購物車件數是一顆小圓點，掛在提袋右上角，**是整條頂欄唯一用強調色的地方**（它是狀態，不是裝飾）。
- 浮在天空上時透明、無線、顏色繼承；捲過天空後有底色和一條細線。窄螢幕只剩圖示，字藏起來（讀屏仍讀得到），搜尋開啟時佔滿一列。
- 穿搭牆照 `FEATURES.wall` 藏；「天氣穿搭」不設連結（首頁第一屏就是它）。

這輪取用了 vault 裡使用者 2026-08-29 喜歡的 sasalasa 視覺語言分析的三項：顏色是事件不是裝飾、細線語彙、襯線寬字距——**用到這個專題是 Claude 的延伸，使用者沒有對這一點表態。**

## `src/theme/themes.js`：每條路線的時刻

`THEME_VISUALS[code].moment = { hour, weather, line }`。路線頁的天空用它，不用今天的天氣。從一條路線換到另一條，太陽與雲是慢慢移過去的（`sky.set()` 只改目標、每幀逼近），不是切換。八個時刻的文字是我寫的，等全組定路線清單時一起看。

## `src/products/weatherFit.js`：今天為什麼是這套

規則拼句，不是生成：每一層一句（是什麼、多厚、適合幾度）；上半身最厚的那層對上今天要的厚度（`wantedWarmth`：26° 以上薄……10° 以下厚）→「這個厚度夠」「偏薄一點，進出室內剛好」「這樣會冷，建議再加一件」；有雨看外層面料吸不吸水（尼龍、皮、防潑水）。門檻是前端暫定，功能規劃 6.1 說之後由後台對照表決定。

## `src/views/OutfitView.vue`：穿搭頁（新）

- 天空：今天的天氣，染這條路線的顏色，高度 86svh。左邊：路線連結＋今天的天氣一行、標題（襯線）、理由幾句（破折號開頭）、整套價格；右邊：`OutfitLook` 460px 高，不帶文字。
- 底下「這套的單品」：每件一列——小圖、類別、名稱（滑過底線畫出）、品牌與顏色、尺寸下拉（無庫存標示、可先不選到購物車再選）、價格、**換一件**。
- **換一件**：展開同路線、同類別、不在這套裡的商品，點一件就換上去——上面的人形、理由句、總價一起變。這是「以穿搭為瀏覽單位」才做得到的事：你在這條路線裡自己搭。
- **滑過一列，人形裡那一件提出來**（`OutfitLook` 的 `highlight`），反過來也能從人形看出哪件是哪件。
- 整套加入購物車：帶著這套選的顏色與你選的尺寸；沒選尺寸的到購物車補；圖飛向頂欄。
- 底下「這條路線的其他穿搭」一排。找不到 → 「找不到這套穿搭」。

## `src/views/ThemeView.vue`、`src/views/OutfitsView.vue`、`src/views/HomeView.vue`

- 路線頁：天空是這條路線的時刻（78svh）；左邊「龐克路線的時刻　／　晚上九點，雨還在下。」、路線名很大、tagline、**換一條路線**（其他七條，滑過畫線）；右邊這條路線的前三套；地平線上「往下，看這條路線全部的穿搭」；底下一句話列與全部穿搭（標題說 N 套）。
- 全部穿搭：矮一點的天空（54svh，今天的天氣）、「8 條路線，11 套。用下面那句話篩。」
- 首頁：搬到 `SkyPage` 上，功能不變（詞自動換、指到換天空與穿搭、往下到店、量測用的 `__home.probe`）；今天的穿搭與穿搭卡現在都連到穿搭頁，不是路線頁。

## `src/components/OutfitLook.vue`、`OutfitStage.vue`、`OutfitCard.vue`

- `OutfitLook`：多了 `sway`（預設開）與 `highlight`。結構變成 `.swing`（慢慢晃：7 秒一來回 ±0.7°；滑過去盪 1.3 秒）包著 `.stack`（被風推：`rotate(var(--wind) × 5°)`，0.9 秒回正）；兩層分開，動畫才不會互搶 `transform`。被點名的那件往上提 8px、放大 3%。減少動態時全部不動。
- `OutfitStage`：卡片用 `TransitionGroup`，改條件時位移有過程、新卡片依序浮上來；離開的直接拿掉（留著會把格線撐亂）；載入中整格 60% 不透明而不是整頁換成「載入中」；`count` 事件給標題。格線間距從 1.6rem 放大到 4.8rem／3.2rem。
- `OutfitCard`：圖與標題都連到穿搭頁；滑過圖底色加深、標題底線畫出；內距放大。
