## 1. 像刷新的原因與修法：探索區共用一個殼

原因：首頁、路線頁、全部穿搭是三個不同的路由元件，各自包一個 `SkyPage`。在一句話列換風格等於從 `/outfits` 換到 `/themes/street`，整個元件換掉——WebGL 畫布重建、頂欄重畫、捲動位置歸零——看起來就像網頁刷新。

修法：三頁共用一個殼 **`src/views/ExploreView.vue`**（巢狀路由的父層），裡面只有一個 `SkyPage`、一條一句話列、一個穿搭舞台；子路由只換天空裡的內容：

| 路由 | 子元件 | 天空 |
|---|---|---|
| `/` | `views/explore/HomeHero.vue`（原 HomeView 的第一屏） | 今天的天氣，染目前那個詞的顏色，100svh |
| `/themes/:code` | `views/explore/ThemeHero.vue` | 這條路線的時刻，78svh |
| `/outfits` | `views/explore/OutfitsHero.vue` | 今天的天氣，54svh |

- 子頁掛上時把要的天空寫進 `src/stores/explore.js`（`useExploreSky().setSky({ hour, weather, tint, height })`），殼把它交給 `SkyPage`。Vue Router 換子路由時父層不重掛，所以畫布是同一個——用程式驗過：換風格前後 `canvas.sky` 是同一個 DOM 節點。
- 第一屏高度換（100svh ↔ 78svh ↔ 54svh）用 CSS 過渡 0.7 秒，過渡完 `ScrollTrigger.refresh()` 重算位置。
- `scrollBehavior`：殼內換頁（`meta.shell`）留在原地——在店裡換風格不再跳回最上面。
- 店的標題跟著頁面變（「今天全部的穿搭」「街頭路線的穿搭」「全部的穿搭」），後面接「N 套」。
- 舊的 `HomeView.vue`、`ThemeView.vue`、`OutfitsView.vue` 刪掉；`/outfits/:id`（穿搭頁）不在殼裡，它的天空是獨立的（進去時衣服會飛過去）。

## 2. 圓角

`tokens.css` 多兩個變數：`--radius: 1rem`（卡片、面板）、`--radius-sm: 0.55rem`（欄位、小按鈕）。`base.css` 讓所有 `input / select / textarea` 預設小圓角（一句話列的下拉選單只畫底線，自己覆寫成 0）。
套上的地方：穿搭卡（整張，`overflow: hidden`，頂上的主題色線跟著彎）、單品卡的圖、商品頁的大圖底、小圖、購買區塊、尺寸按鈕、數量加減、購物車的金額區與數量加減、穿搭頁被點名的那一列與候選單品、試做頁的讀數與按鈕，以及會員與結帳 8 頁裡「白底加一條線」的面板（用腳本掃：同一個 CSS 區塊裡同時有 `border: 1px solid var(--line)` 與 `background: var(--surface)` 的，加上 `--radius`；共 10 處）。

## 3. 穿搭卡的商品名目 hover

`OutfitCard.vue`：每一件是一列，滑過整列亮起來（主題色加大量白的底，和卡片的圖同一套）、名稱底下的線畫出來，**而且卡片上方人形裡那一件會提出來**（`OutfitLook` 的 `highlight`，和穿搭頁同一個機制）——看一眼就知道這列是人形裡的哪一件。名稱連到商品頁時帶著這套穿搭選的顏色；品牌後面補了顏色名。

## 4. 給誰穿

一句話列多一格，在天氣後面：「今天 18°C，〔不限誰〕，〔哪裡都去〕，想穿〔什麼風格都好〕，找〔整套穿搭〕，尺寸〔不限〕。」選項：女生、男生、中性、小孩。
- 網址：`?for=women|men|unisex|kids`（`useFilters` 的 `audience`）。
- 規則（`api/index.js` 的 `forAudience`）：選女生會連中性的一起出現，選男生也是；中性只給中性；小孩只給小孩。這是我定的，可改。
- 資料：每套穿搭多 `audience` 欄位（11 套各標了；契約文件的穿搭表要加這欄）；**新增一套小孩的穿搭「公園的下午」**（戶外路線：兒童防潑水連帽外套、兒童條紋長袖T、兒童束口褲，尺寸 110／120／130，童裝尺寸表另有一組基準值），不然「小孩」篩出來是空的。商品現在 35 件、穿搭 12 套。
- 搜尋也搜得到：標籤有「小孩」「兒童」。

## 5. 飛入購物車

`useFlyToCart.js`：0.62 秒縮到 6% → **1.05 秒**、先往上抬再落向提袋、縮到 20% 才消失；飛到的那一刻才送 `cart:arrive`，頂欄的提袋接一下、件數跳一下（件數本身按下的瞬間就更新了，不等動畫）。減少動態或頂欄不在畫面裡時直接送 `cart:arrive`。
