# 13　第十五輪・插曲：頂欄圖示的預覽

2026-10-06，使用者在子輪 3 進行中提出：「右上的 icon 們增加 link 以外的作用，比如購物車 hover 或點開為小視窗能預覽購物車，諸如此類的 UX 提升。」規格 09 沒有這一項；做完子輪 3 就接著做，一個 commit。

## 做了什麼（一句話）

頂欄四個圖示（全部穿搭、收藏、購物車、會員）點下去還是原本的連結，但滑到或 Tab 到會多一個小面板：全部穿搭列八條路線、收藏看最近收的、購物車看裡面有什麼並可直接去結帳、會員是小選單。只在桌機；手機點下去就是去那一頁。

## 逐檔

- `src/components/HeaderPopover.vue`（新）：包住一個頂欄連結的殼。`pointerenter` 停 120 ms 才開（滑過去不會閃）、`pointerleave` 寬限 220 ms 才關（從圖示移到面板不會關）；鍵盤 `focusin` 開、焦點離開整個殼關、Esc 關並把焦點還給連結。面板 `role="group"` 有名字；`<Transition>` 淡入、下滑 4px。只在 `(min-width: 48rem)` 開，觸控的 `pointerenter` 不算——手機與平板點圖示就是要去那一頁，面板只會閃一下礙事。`wide` 給兩欄內容放寬。
- `src/components/peeks/CartPeek.vue`（新）：購物車裡有幾件、最多四列（圖、名稱、顏色・尺寸 × 件數、金額）、「還有 N 列」、小計、看購物車／去結帳；空的就說空的並指去穿搭。商品圖的款式與顏色要商品資料，打開時才去要；名稱與價格用購物車存的快照。
- `src/components/peeks/FavPeek.vue`（新）：收藏了幾件單品、幾套穿搭；最近收的四件單品的圖（連到商品頁、帶收藏時的顏色）；看全部收藏。空的說明訪客也能收。
- `src/components/peeks/MemberPeek.vue`（新）：登入了是名字加小選單（個人資料、訂單紀錄、看過的、登出）；沒登入是「還沒登入」、一句為什麼要登入、登入／註冊兩顆鈕。
- `src/components/peeks/RoutesPeek.vue`（新）：八條路線兩欄，各帶自己的顏色點與一句話；底下全部穿搭、全部單品。
- `src/components/SiteHeader.vue`：四個連結各包進 `HeaderPopover`；飛入動畫的目標 `.cart-link`、`.fav-link` 不變。

## 實測了什麼

- `expand-check` 第四段 9 項（桌機）：滑到購物車 → 面板有那件 M 的大衣與小計、有看購物車與去結帳；滑到收藏 → 「0 件單品、1 套穿搭」；滑到全部穿搭 → 八個路線連結；滑到會員 → 名字與登出；滑走 → 關；Tab 到購物車 → 開；Esc → 關且焦點留在連結；面板開著時沒有東西溢出。手機 1 項：focus 購物車不開面板。合計桌機 108／108、手機 100／100；`shop-check` 60、`member-check` 39 不退。
- 截圖看過：購物車面板、八條路線面板。
- **沒有驗證**：使用者本人的手感（120／220 ms 的門檻）；平板（觸控但 ≥ 48rem）只靠 `pointerType === 'touch'` 擋，沒實機；讀屏。
