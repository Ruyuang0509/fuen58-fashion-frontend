# 02　入口「天空」逐檔解說

2026-10-06。這一版入口是在使用者說「棄置前七輪、風格技術呈現由 Claude 自行決定、功能不減」之後做的。
前七輪的原型檔還在 `src/views/design/`，路徑已從 router 註解掉，等使用者說一聲再刪。

## 這個入口是什麼

首頁分兩段：**天空在上，店在下**（2026-10-06 使用者裁決：這個風格可以繼續；入場島不再是獨立的一頁，而是首頁的第一屏）。

第一屏的底是**現在的天空**：時間決定太陽（白天藍、傍晚暖、夜裡深），今天的天氣決定雲、雨、霧。
畫面上只有一句話：「臺北，10 月 6 日，18°，濕度 85%，有雨。」「今天，走［簡約］路線。」
括號裡的詞是風格；底下排著全部的風格，指到就換，點進去就到那個風格的穿搭列表。
沒有人動的時候，詞自己每 3.6 秒換一個，像在想；一碰就停。右邊是這個風格裡、合今天天氣的幾套穿搭。
天空在最下面淡進紙色（地平線），地平線上一行「往下，看今天全部的穿搭 ↓」。

往下是店：共用的頂欄（搜尋、四個連結、購物車數量）黏在最上面——在天空上是透明的，捲過天空後變回有底色的；
共用的一句話篩選列黏在頂欄下面；接著是全部的穿搭（`OutfitStage`，卡片的圖換成了三件疊成的人形）；最後是頁尾。
天空捲出畫面時停下來（IntersectionObserver），捲回來再動。

為什麼這樣做（Claude 的判斷）：

- 站名本身是一個問句，企劃的特色是「天氣接到穿搭」。所以入口不放裝飾，直接把「今天」做成底，把問句做成介面。
- 沒有商品照片的現在，畫面的真實感來自天空與排版，不來自衣服的圖。衣服的圖換成照片時版面不變。
- 介面方向筆記裡定過「一句話篩選」「以穿搭為瀏覽單位」：入口那句大字就是一句話篩選的第一格，右邊的穿搭就是瀏覽單位。
- 風格數量不限：詞列多幾個就是多幾個，不用重排版面。

## 檔案

### `src/sky/sky.js`

天空。一個 WebGL 片段著色器畫滿整個畫布：

- `uSun`／`uSunX`：太陽高度與左右位置，由 `sunNow()` 從現在時間算（6 點出、18 點落，粗略的）。高度決定天頂與地平線的顏色、日出日落的暖色帶、太陽的柔光。
- `uCloud`／`uRain`／`uHaze`：由 `weatherLook(weather)` 從天氣算。雲是兩層不同大小的 fbm 雜訊，往上取樣一點當作雲的明暗；雨是每一欄有自己相位與速度的細線；霧讓地平線附近變灰。
- `uTint`／`uTintK`：風格的顏色淡淡地染進天空。
- `uWind`：滑鼠移動推出來的風，雲會被推一下（`stir()`）。
- 所有參數每一幀往目標靠近一點（`set()` 只改目標），天氣或風格換的時候才不會跳。
- 沒有 WebGL：退回 CSS 漸層，顏色一樣跟著時間與天氣，只是沒有雲在動。
- `skyWantsDarkText()`：這片天空上的字該不該用深色。

### `src/views/HomeView.vue`

首頁本身。`bare` 路由，自己組頁面：`SiteHeader`（黏在上面）→ 天空第一屏 → `SentenceBar` → `OutfitStage` → `SiteFooter`。

- 狀態：`active`（括號裡的風格）、`touched`（使用者碰過沒；碰過就不自動換）、`pastHero`（捲過天空了沒）、`weather`、`outfits`。
- `choose(code)` 換詞並重畫天空；`go(code)` 進那個風格的穿搭列表；`startCycle()` 自動換詞（減少動態時、捲過天空後都不換）。
- `picks`：這個風格的穿搭，冷或下雨時有外套的排前面，取三套。
- 詞是 `<button>`，鍵盤走到也會換；括號本身也是按鈕。
- `IntersectionObserver` 看著天空：捲出去就 `sky.pause()`、頂欄換成有底色的；捲回來 `sky.resume()`。
- `SentenceBar` 收合的門檻用 `offset` 往下推（天空的高度再加 320px），進店時先看得到整句。
- 窄螢幕：天空裡上下排，穿搭列可以左右滑；頂欄照共用的規則變成靜態的兩列。

### `src/components/SiteHeader.vue`、`src/components/SentenceBar.vue`、`src/components/OutfitCard.vue`

共用元件這一輪各改一點：

- `SiteHeader` 多了 `float` 屬性：浮在天空上時透明、沒有線、顏色繼承。
- `SentenceBar` 多了 `offset` 屬性：收合的門檻從指定高度起算。
- `OutfitCard` 的「圖片待補」色塊換成 `OutfitLook`（三件疊成人形），正式版換照片時只動這一處。

### `src/components/OutfitLook.vue`

一套穿搭的樣子：上衣、外套、下身三件疊成一個人形，下面是標題、品牌與總價。
單品圖由 `src/garments/render.js` 把款式圖打光畫出來；正式版每件換成商品去背照片，版面不變。
配件與鞋在入口不畫。

### `src/garments/render.js`、`src/garments/flats.js`

款式圖的路徑資料與「打光」渲染（第七輪做的，沿用）：底色、整體光、輪廓內陰影、沿車縫線的皺褶、布料紋理、車縫線、鈕扣。

### `src/api/index.js`、`src/api/mock/outfits.json`、`src/api/mock/themes.json`

- `getWeather()` 多了 `city`、`condition`（clear | cloudy | rain）、`observedAt`。正式版接後端的氣象資料。
- 穿搭的每件單品多了 `kind`（款式）與 `colour`（布色）兩個渲染用的欄位，正式版由商品圖取代。另外加了龐克、蘿莉塔、量產型各一套，讓八個風格都有東西可看。
- 主題清單是八個暫定風格；正式清單由全組決定。

### `src/router/index.js`

`/` 改為 `bare`（入口自己畫頂欄，不套共用的 SiteHeader 與 SentenceBar）。`/design/*` 的原型路徑整段註解。
